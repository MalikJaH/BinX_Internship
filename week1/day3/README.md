
## Day 3 — NumPy Fundamentals

On Day 3, I refreshed my knowledge of the NumPy library and practiced working with multidimensional arrays.

NumPy is a powerful Python library used for numerical calculations and data manipulation. It makes operations on arrays faster and more convenient than working with regular Python lists.

During this day, I practiced several important NumPy concepts:

- Creating arrays using arange().
- Changing array dimensions using reshape().
- Accessing rows and columns using indexing and slicing.
- Calculating statistical values such as the mean.
- Filtering arrays using Boolean conditions.
- Adding a one-dimensional array to a two-dimensional array using broadcasting.

I enjoyed solving the four practical tasks because they helped me understand how NumPy operations work in real examples.
