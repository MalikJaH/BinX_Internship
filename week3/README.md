# Week 3 Summary

During **Week 3**, I focused on supervised machine learning and learned how to build, train, compare, and evaluate different models.

I started by learning how to use **Pipelines**, **GridSearchCV**, and train/test splitting. I understood why the test set must remain unseen during training and how cross-validation can help when choosing model parameters.

Then, I studied **Linear Regression** and learned how the best-fit line works, including the slope, intercept, and residuals. I also practiced evaluating regression models using **MAE, RMSE, and R²**, and compared the model against a simple baseline.

After that, I moved to **classification** and trained a **Logistic Regression** model on the Titanic dataset. I learned how to evaluate classification models using the confusion matrix, Precision, Recall, F1-score, and AUC-ROC.

I also studied and compared several classification algorithms:

* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (K-NN)

I learned the main idea behind each model, their advantages and disadvantages, the importance of feature scaling for some models, and how to compare them using the same evaluation metric.

Finally, I completed a **Titanic Survival Classification Mini-Project**, where I applied the full workflow from data exploration and preprocessing to cross-validation, model comparison, final test evaluation, and confusion matrix analysis.

Overall, Week 3 helped me connect the different parts of a supervised machine learning workflow and understand how to choose and evaluate models more correctly.
